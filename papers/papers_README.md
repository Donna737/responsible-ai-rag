# Papers

This folder should contain the 20 PDF papers used to build the RAG corpus.
They are not included in this repository for copyright reasons.

Search for each title on [arXiv.org](https://arxiv.org) or
[Semantic Scholar](https://semanticscholar.org) to download the PDFs,
then place them in this folder and run `streamlit run app.py` —
the vector store will build automatically on first run.

## Topics Covered

- Fairness, bias mitigation, and algorithmic discrimination
- Transparency, explainability, and the black box problem
- Accountability and auditability in AI systems
- AI governance and regulatory frameworks (EU AI Act)
- Power dynamics between AI developers and affected communities
- Responsible AI in high-stakes domains (healthcare, education, marketing)
- Sociotechnical approaches to responsible AI practice
